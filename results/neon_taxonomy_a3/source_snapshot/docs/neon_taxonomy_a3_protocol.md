# A3: explicit accepted-species synonym extension

17 November 2026. This targeted **development correction** follows A2's
post-hoc metadata screen (736 selected records / 166 cell–concept candidates).
Those observations and earlier scores are consumed. Freeze this extension's
rules before its new label generation/scoring; no fresh-confirmation claim.

Use the same selected A2 caches, public taxonomy and fixed E4 universe/native
masks. Group species-rank dictionary names by their terminal explicit
accepted-species ID. Match model names to dictionary species names exactly,
using the existing declared-authorship normalization. Extend an unmatched named
taxon only when its terminal species group contains exactly **one model class
across all 5,771 classes**. A single eligible candidate out of several global
classes is not sufficient. Missing/cyclic chains, terminal infraspecific taxa
and higher-rank records remain unresolved.

This is an extension of existing class-name targets, not a new merged biological
ontology: retain A2's existing exact class-name mappings, and never choose among
multiple aliases for a newly matched record. The distinction between nominal
model classes and accepted biological concepts remains a limitation. No fuzzy
name matching, inferred infraspecific parent, class-universe expansion, history
replacement or forced positive-genus constraint is permitted. Qualifier, rank,
current-record conflict, quality and uncertainty-mask handling remain A2's.

Report the new dictionary links and current positive-record witnesses without
publishing plot–taxon records. Reuse cached data: no new plots, HTTP composition
requests, model fits or GPU jobs. Freeze labels before scoring. Compare A2 and
A3 on the same fixed original 65, previous 77, all 163 and A2-admitted 31 cells;
also describe the A3 >=80%-known subset. Apply identical 80% site/plot-count
quotas within each cohort, fixed prediction sets and score definitions, 97.5%
paired site intervals, and full-set completion ranges. Changing the observed
labels changes the scoring estimand; there is no complete field oracle.

The original E4 primary and every A2 arm remain preserved. The old 100-cell /
12-site requirement is a descriptive reference only. No result can retroactively
restore prospective admission. Exact synonym harmonization is established
practice, not a new algorithm or independent taxonomic-concept validation.
